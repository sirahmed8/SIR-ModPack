# Production Engineering Standards & Zero-Bug Protocols

This skill dictates core engineering protocols to ensure every feature built by the agent is complete, fully functional, resilient, and ready for immediate real-world use without lingering bugs or placeholders.

## Core Pillars
1. Zero-Mock Persistence Engines & Data Layers (Real files, Real Win32 APIs, Real sockets).
2. Runtime Schema Validation & Data Contracts.
3. Defensive Zero-Bug Engineering & Utilities (Atomic writes, non-blocking async bridges, resilient backoff downloaders).
4. Strictly Modular Multi-File Architecture.
5. Rigorous Automated Testing and Verification (100% test pass rate).
