## 🌟 What is SIR ModPack?
**SIR ModPack** is an enterprise-grade Minecraft distribution and desktop ecosystem unifying **Modern 26.2 (Fabric 1.21.4)** and **Legacy 1.8.9 (Forge/Paper PvP)**. It provides one public SIR ModPack.exe dispatcher, custom shaders, 3D POM textures, zero-port server hosting, and a high-performance web platform. Launcher, Installer & Repair, and Server Host are internal dispatcher modes.

---

## 📦 Core Applications

| Application | Binary | Description |
| :--- | :--- | :--- |
| **SIR ModPack dispatcher** | `SIR ModPack.exe` | One public EXE with --mode launcher, --mode installer, and --mode server. |
| **SIR Web Platform** | `sir-modpack.web.app` | Next.js 16 portal with 27 prerendered static routes, bilingual RTL/LTR engine, and SWR caching. |

## ⚡ Quickstart

### 1. Run SIR ModPack:
Double-click SIR ModPack.exe, or choose a mode explicitly with --mode launcher, --mode installer, or --mode server.

### 2. Run the Next.js Web Platform:
```bash
cd website-next
npm run dev
# Open http://localhost:3000
```
