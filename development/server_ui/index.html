Server Hosting Quick Reference & Architecture Guide GENESIS v1.0.0

Complete walkthrough for LAN, Dedicated Hosting, Playit.gg Cloud Tunnels & Bedrock Cross-Play

1. Zero-Download In-Game LAN (e4mc)

In any singleplayer world, open the game menu (Esc) and click "Open to LAN". The bundled e4mc engine creates a secure public tunnel URL instantly without router port forwarding.

2. Dedicated Standalone Server

Launch this Server Orchestrator on your PC or secondary machine. Uses bundled Java 21 LTS with Aikar's high-performance G1GC flags, discrete RAM tuning (2 to 24 GB), and an automated background crash recovery watchdog.

3. Playit.gg Zero-Port Forwarding

Under Network & Cloud Tunnels, start the Playit tunnel service or paste your secret key. You receive a permanent static domain (e.g., your-host.ply.gg) so external friends can join safely.

4. Bedrock Cross-Play (GeyserMC)

Open the Plugins & Mods Store tab, find GeyserMC + Floodgate, and click 1-Click Install. Mobile (iOS/Android) and console players can connect using port 19132 with Java authentication bypass.

Cloud Sync & Snapshot Backups

Connect your Google account via native OAuth in the top navbar. Your server configurations, operator lists, whitelists, and world backup metadata are safely mirrored to Firebase under /users/{uid}/server_orchestrator.
