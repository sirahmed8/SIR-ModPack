## ⚡ What is SIR ModPack?
**SIR ModPack** is a state-of-the-art Minecraft platform integrating both **Modern 26.2 (Fabric)** and **Legacy 1.8.9 (Forge)** into a single unified client and launcher ecosystem.

### 🌟 Core Highlights
- **Adaptive Dual Engine:** Seamlessly launch Modern 26.2 Fabric with Iris & Sodium, or Legacy 1.8.9 Forge with OptiFine & Patcher.
- **2048 HD Volumetric Bliss Shaders:** Physics-based glowing circular sun, crystal-clear water with dynamic caustics, and ACES cinematic tonemapping.
- **3D Parallax Occlusion Mapping (POM):** 32x high-resolution relief textures with progressive 3D block break stages.
- **Fresh Animations & Living Mobs:** Entity Model Features (EMF) and Entity Texture Features (ETF) for fluid player and mob movement.
- **InGameAccountSwitcher (IAS):** Switch between Microsoft official and Offline / Cracked alt accounts directly from the main menu.
- **Hardware Power Governor:** Choose between *Max Performance Mode* and *Smooth / Eco Mode* to prevent CPU stutter and keep background tasks 100% fluid.
