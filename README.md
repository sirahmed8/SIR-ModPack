## English Quick Start Guide
1. **Extract**: Right-click `SIR_Apps_Suite.zip` and choose **"Extract All..."** (or use 7-Zip / WinRAR).
2. **Install**: Double-click **`install.bat`** (or directly run **`SIR Installer.exe`**).
3. **Enjoy**: The application will set up and launch immediately with full hardware acceleration.

### System Requirements
- **OS**: Windows 10 / Windows 11 (64-bit)
- **Architecture**: x64 / AMD64
- **Privileges**: Standard user (elevated for system driver hooks if applicable)
