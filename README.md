## 🚀 Key Highlights & Innovations

### 1. 🎮 Dual Engine Architecture
* **Modern 26.2 (Fabric):** Tuned with Sodium, Iris, Lithium, FerriteCore, C2ME, and ImmediatelyFast for maximum visual fidelity and 144+ FPS.
* **Legacy 1.8.9 (Forge PvP):** Optimized for competitive 1000Hz raw input, 1.7 animation mechanics, fast math, and 500+ FPS.
* **InGameAccountSwitcher (IAS):** Switch between official Microsoft accounts and offline / cracked accounts in 1 second right from the in-game menu.

### 2. ⚡ Universal Multiplayer & Hosting Suite
* **🎮 In-Game 1-Click World Host:** Host your singleplayer world publicly in 2 seconds (`Esc ➔ Open to LAN ➔ Host World`). Friends can join immediately with zero port forwarding!
* **⚡ Standalone SIR Server Host App:** Native Windows executable with **Intelligent Java 21 Auto-Detection**, live player admin management (👑 OP / 👢 Kick), visual `server.properties` editor, 1-click modpack sync, and auto-backups.

### 3. 🌊 Master Physics Shaders (Extreme & Balanced)
* **Crystal Water & Dynamic Caustics:** Realistic transparent water with procedural Voronoi sunlight caustics and multi-frequency Gerstner wave spectrums.
* **Circular Physics Sun & Detailed Moon:** Accurate limb-darkening solar disk, corona flares, and high-definition lunar phases.
* **Distant Horizons Depth Buffer Fix:** 100% distortion-free LOD rendering with zero vertical stretching.

### 4. 🛡️ Smart Granular Single-File Auto-Healing Installer
* **Single-File Delta Downloader:** Verifies every mod, shader, and config individually. If any file is missing, it fetches **ONLY that missing file** from high-speed CDNs.
* **Smart Offline Detection:** Automatically detects if the full bundle is present locally and hides unnecessary prompts for an instant 1-click installation.
* **Hardware Power Governor:** Choose between *⚡ Max Performance Mode* and *🍃 Smooth / Eco Mode* (low I/O priority for 0% PC lag).

## 🛠️ Quick Start & Installation

1. Visit the **[Official SIR Platform](https://sir-modpack.web.app/#downloads)**.
2. Download **`SIR Installer.exe`**.
3. Choose your preferred profiles (*Modern 26.2*, *Legacy 1.8.9*, or *Both*).
4. *(Optional)* Check **Install Standalone SIR Server Host App** if you want to host dedicated servers.
5. Click **Install SIR Ultimate** and enjoy!
