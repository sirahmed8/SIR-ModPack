## 1. نظرة عامة شاملة على منصة SIR ModPack

منظومة **SIR ModPack (الإصدار v1.0.0 الرسمي)** هي بيئة ألعاب وبرمجيات مكتبية متطورة وهندسة حاسوبية موحدة فائقة الأداء، تم إنشاؤها لتقديم أرقى تجربة ممكنة في عالم ماينكرافت. تُعد المنظومة منصة ألعاب متطورة ومستقلة تخضع لـ **اتفاقية برمجيات منظومة SIR الرسمية (SIR Software Agreement)**، وتجمع في بيئة واحدة بين أحدث تقنيات المعالجة الصورية ومحركات التشغيل المزدوجة.

تدمج المنظومة بين عالمين متميزين:
1. **المحرك الحديث (Modern 26.2):** تجربة بصرية فائقة الواقعية تدعم أحدث ميزات اللعبة عبر بروفايلات متدرجة فائقة الضبط تحت مظلة بيئة Fabric ومحرك تعديل بايتكود ASM مخصص.
2. **المحرك الكلاسيكي (Legacy 1.8.9):** بيئة المعارك التنافسية (PvP Battle Suite) المبنية على Forge مع 28 موداً متطوراً، لتحقيق زمن استجابة صفري (0ms Input Lag) ومعدل إطارات يتجاوز 600 إطار بالثانية.

تأتي المنظومة بحزمة برمجية متكاملة تشمل:
- تطبيقات تنفيذية مستقلة ذاتية التشغيل (Native Executables) بدون الحاجة إلى أدوات تثبيت خارجية معقدة.
- خط أنابيب الإطلاق المباشر عبر جهاز جافا الافتراضي (`Direct JVM Launch Pipeline`) المتوافق مع Java 8 و Java 21 و Java 25.
- شيدرز Master SIR المطورة والمعزولة بالكامل لدعم الواقعية والإضاءة الحجمية.
- حزم موارد ثلاثية الأبعاد تدعم مجسمات PBR/POM وتأثيرات أمواج المحيطات الفيزيائية.
- استوديو واجهة المستخدم في اللعبة R-Shift HUD ودعم متقدم لبروفايلات Lunar Client.
- مدير خوادم مدمج يتيح استضافة سيرفرات اللعب الجماعي ومشاركتها مباشرة عبر أنفاق Playit.gg المدمجة دون الحاجة لفتح منافذ الراوتر (Port Forwarding).
- بوابة سحابية حديثة مبنية على Next.js 16 تضم 38 مساراً ساكناً مسبق المعالجة، تدعم مزامنة السكنات والبروفايلات وتقدم مساعد SIR Diagnostic & Configuration Assistant.

## 2. هندسة المحركين المزدوجة (Dual-Engine Architecture)

صُممت المنظومة لتلبي احتياجات جميع اللاعبين، من عشاق الرسومات السينمائية الخارقة إلى محترفي ألعاب التنافس والمبارزات السريعة (PvP و Bedwars):

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                           SIR MODPACK DUAL ENGINE                                │
├─────────────────────────────────────────┬────────────────────────────────────────┤
│           MODERN ENGINE 26.2            │           LEGACY ENGINE 1.8.9          │
├─────────────────────────────────────────┼────────────────────────────────────────┤
│ • الإصدار: Minecraft 26.2               │ • الإصدار: Minecraft 1.8.9             │
│ • اللودر: Fabric 0.19.4                 │ • اللودر: Forge 2318 (PvP Edition)     │
│ • عدد المودات: 221 موداً نشطاً           │ • عدد المودات: 28 موداً قتالياً         │
│ • محرك التوافق: ASM Bytecode Engine     │ • زمن الاستجابة: 0ms Raw Input Lag     │
│ • الرسوميات: Sodium + Iris 2.0          │ • الرسوميات: OptiFine HD U M5          │
│ • بيئة التشغيل: Eclipse Temurin 21/25   │ • بيئة التشغيل: Java 8 64-bit          │
│ • معدل الإطارات: 144 إلى 350+ FPS       │ • معدل الإطارات: 450 إلى 600+ FPS      │
│ • إدارة الذاكرة: Generational ZGC       │ • إدارة الذاكرة: Tuned Low-Latency G1  │
└─────────────────────────────────────────┴────────────────────────────────────────┘
```

### أولاً: المحرك الحديث (Modern Engine 26.2)
- **محرك معالجة البايتكود التوافقي (ASM Bytecode Engine):** يقوم بتحويل الـ Bytecode للمودات آلياً من فضاء أسماء Fabric Intermediary إلى فضاء أسماء Mojang Official Mappings في زمن قياسي، مع إزالة التواقيع الرقمية الرسمية (`Mojang Signature Stripping`) لمنع تعارض الحزم، مما يضمن عمل 221 موداً متناسقاً دون أي انهيار برمجى.
- **محرك إدارة الذاكرة الخارق (Generational ZGC):** تفعيل تلقائي لمعاملات `-XX:+UseZGC -XX:+ZGenerational` لبيئات Java 21+ والأنظمة التي تملك 6 جيجابايت رام فأكثر، مما يقلص فترات تجميد تفريغ الذاكرة (GC Pauses) إلى أجزاء من الميلي ثانية (Sub-millisecond)، ويمنع التقطيع اللحظي (Micro-stutters) أثناء التحميل السريع للمناطق والشيدرز.
- **حزم التوافق الشامل للشبكات:** حل جذري لكافة أخطاء الاتصال بالخوادم البعيدة وضمان الاتصال بنسبة 100% بكافة خوادم Purpur و Paper و Vanilla.

### ثانياً: المحرك الكلاسيكي التنافسي (Legacy Engine 1.8.9)
- **أقصى درجات الاستجابة التنافسية:** ترقية شاملة لمحرك Forge 1.8.9 مع تثبيت وتكامل 28 موداً تنافسياً معتمداً ومطابقاً للوائح اللعب النظيف على كبرى السيرفرات (مثل Hypixel و Minemen Club).
- **محرك السحب الخام للفأرة (Raw Input Engine):** تجاوز طبقات Windows لإلغاء أي تسارع غير مرغوب، مما يمنح دقة تصويب مثالية وثباتاً في مسافات الضربات (Hit Registration).
- **إدارة الموارد الخفيفة:** استهلاك منخفض للغاية للذاكرة العشوائية (1.5 إلى 3 جيجابايت فقط) مع إطارات تتجاوز 500-600 إطار بالثانية حتى على الأجهزة المتوسطة.

## 3. الشيدرز، الإضاءة ثلاثية الأبعاد PBR/POM، والأنماط السريعة

تحتوي المنظومة على هيكلية شيدرز معزولة ومخصصة تم ضبطها وبرمجتها لتوفير أعلى جودة بصرية ممكنة دون التضحية باستقرار الأداء:

### الشيدرز المعزولة المزدوجة (Dedicated Isolated Shaders)
1. **شيدر الحديث `SIR Modern Shader.zip`:** شيدر متطور مبني على محرك Iris الرسومي، يقدم إضاءة حجمية واقعية (Volumetric Rays)، وانعكاسات مائية دقيقة مع ظلال ديناميكية للسحب، وتوافقاً كاملاً مع مود المستنقعات والمياه `Puddleflood` عبر قنوات `layer.translucent` لمنع أي تشوه بصري عند انعكاس الأمطار.
2. **شيدر الكلاسيكي `SIR Legacy Shader.zip`:** مخصص لمحرك OptiFine 1.8.9، يمنح أجواء بصرية خلابة وألواناً زاهية وظلالاً ناعمة مع الحفاظ على سرعة حركة اللعبة المناسبة لمباريات الـ PvP السريعة.

### حزم الموارد ثلاثية الأبعاد PBR و POM
- تتضمن المنظومة حزمة الموارد الملكية **`SIR Modern.zip`** المدمجة بنماذج **Patrix 3D POM (Parallax Occlusion Mapping)** ومحاكاة الأسطح البارزة (PBR - Physically Based Rendering)، مما يمنح البلوكات والمباني عمقاً مجسماً واقعياً تتفاعل معه مصادر الضوء والمشاعل.
- محاكاة فيزيائية واقعية للأمواج المائية والمحيطات عبر ملف التهيئة المتقدم `physics_client_config.json`، والذي يضيف أمواجاً متلاطمة، ورغوة مائية متطايرة، وقوى طفو تفاعلية للأجسام والقوارب.
- حزمة **`SIR Legacy.zip`** بوضوح 32x مصممة خصيصاً لمباريات الساحة لتقديم سيف قصير مريح، وجزيئات واضحة، وسماء ليلية فلكية رائعة.

### الأنماط السريعة بنقرة واحدة
توفر المنظومة 5 أنماط فيديو فورية يتم تطبيقها بنقرة واحدة وتعدل كافة ملفات التهيئة (`options.txt`، `sodium-options.json`، `iris.properties`، `optionsshaders.txt`) بالتزامن:

| نمط الفيديو | مسافة الرؤية | الشيدر المستخدم | المعالجة والمؤثرات | معدل الإطارات المستهدف | الفئة المناسبة |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Potato PC** | 4 Chunks | معطل تماماً | إيقاف الظلال والجسيمات، تسريع أوراق الأشجار | **150+ FPS** | الأجهزة الضعيفة وكروت الشاشة المدمجة (Intel HD) |
| **Competitive PvP** | 8 Chunks | معطل تماماً | إدخال خام للفأرة، إيقاف تشتيت الجزيئات | **500+ FPS** | مباريات التنافس والسرعة الفائقة (0ms Lag) |
| **Performance** | 8 Chunks | معطل (Sodium Boost) | معالجة فورية للمناطق، إضاءة سلسة سريعة | **350+ FPS** | اللعب اليومي السلس مع أعلى توفير للموارد |
| **Balanced (144Hz)** | 12 Chunks | SIR Modern / Legacy | إضاءة ناعمة، انكسار مائي خفيف، ظلال محسنة | **180+ FPS** | شاشات 144Hz و 165Hz بتوازن مثالي |

## 4. استوديو واجهة المستخدم في اللعبة R-Shift HUD ودعم Lunar Client

تتميز المنظومة بوجود استوديو متكامل للواجهة الرسومية أثناء اللعب، يمكن الوصول إليه وتخصيصه بالكامل بضغطة زر واحدة:

### استوديو الـ HUD عبر زر Shift الأيمن (Right Shift)
عند الضغط على مفتاح **`R-SHIFT` (Shift الأيمن)** في لوحة المفاتيح أثناء التواجد داخل اللعبة، تفتح واجهة التخصيص التفاعلية للتحكم في عناصر الشاشة بالسحب والإفلات:
- **عداد مسافة الضرب (Reach Display):** يقيس بدقة متناهية (0.01 بلوك) المسافة الفعلية للضربات أثناء الاشتباك.
- **عداد الكومبو (Combo Counter):** شاشة رقمية تفاعلية تحسب الضربات المتتالية على الخصم.
- **عداد النقرات بالثانية (CPS Display):** رصد منفصل ودقيق لنقرات الفأرة اليسرى واليمنى (Left / Right CPS).
- **مقياس زمن التأخير (Ping Latency Meter):** رصد حي لزمن الاتصال بالخادم بالميلي ثانية مع تنبيهات عند تذبذب الشبكة.
- **حالة الدروع والمعدات (Armor Status HUD):** عرض الدروع والأدوات المحمولة مع أشرطة ملونة لنسبة المتانة المتبقية ورقم الاستهلاك الفعلي.
- **مؤثرات الجرعات (Potion Effects HUD):** بطاقات كبسولية شبه شفافة أنيقة تعرض التأثيرات المكتسبة مع العد التنازلي الزمني.
- **رادار العتاد المتقدم (BetterF3 / Hardware Overlay):** شاشة بيانات F3 مطورة ومقسمة إلى أعمدة ذكية تعرض استهلاك كارت الشاشة الفعلي (GPU Utilization %)، واستهلاك ذاكرة الفيديو VRAM، والإحداثيات الجغرافية.

### دعم وترقية بروفايلات Lunar Client التلقائي
تتعرف المنظومة تلقائياً على تثبيتات مشغل **Lunar Client** في الجهاز (`%USERPROFILE%\.lunarclient\`) وتقوم بحقن تحسينات أداء خارقة:
- حقن معاملات JVM فائقة السرعة ومنخفضة التأخير (`-XX:+UseG1GC -XX:MaxGCPauseMillis=20 -XX:+AlwaysPreTouch -XX:+UseStringDeduplication`).
- تهيئة ملف `performance.json` بتفعيل خيارات التسريع الرسومي.
- ضبط وتوزيع الذاكرة التلقائي (8GB لبروفايل Visuals، و6GB لبروفايل Balanced، و4GB لبروفايل Performance).

## 5. باقة برامج سطح المكتب الأساسية

تتألف منظومة SIR ModPack من ثلاثة تطبيقات مكتبية مستقلة تعمل بتناغم تام ومبنية وفق أعلى معايير هندسة البرمجيات:

```
                  ┌──────────────────────────────────────────────┐
                  │          SIR MODPACK APPS SUITE              │
                  └──────────────────────┬───────────────────────┘
                                         │
        ┌────────────────────────────────┼───────────────────────────────┐
        ▼                                ▼                               ▼
┌─────────────────────────┐  ┌──────────────────────────┐  ┌─────────────────────────┐
│     SIR LAUNCHER        │  │       SIR INSTALLER      │  │   SIR SERVER MANAGER    │
├─────────────────────────┤  ├──────────────────────────┤  ├─────────────────────────┤
│ • تشغيل فوري للبروفايلات│  │ • فحص استباقي وعتادي     │  │ • استضافة بضغطة زر واحدة│
│ • استوديو سكنات 3D      │  │ • تدفق الحزم عبر السحابة │  │ • أنفاق Playit.gg المدمجة│
│ • تبديل الحسابات الذاتي │  │ • استخراج بدون فقد بيانات│  │ • عدادات حية لـ TPS     │
│ • استشفاء ذاتي للملفات  │  │ • فحص CRC32 و SHA-256    │  │ • مراقبة الرام واللاعبين│
│ • إدارة دورة حياة النافذة│  │ • تحديثات دون فقد تهيئة │  │ • تحكم بدورة تشغيل النافذة│
└─────────────────────────┘  └──────────────────────────┘  └─────────────────────────┘
```

### 1. مشغل SIR Launcher Pro (`SIR Launcher.exe`)
- **تصميم عصري متناسق (Anti-Vibe):** واجهة أوبسيديانية زجاجية داكنة خالية من الوميض، تعتمد تدرجات الأردواز والسماوي والأزرق النقي وتستبعد تماماً الألوان البنفسجية العشوائية وأزرار الحبوب (Pill Buttons).
- **الإطلاق المباشر عبر جهاز جافا (Direct JVM Pipeline):** بناء الـ Classpath ديناميكياً مع استخراج مباشر لمكتبات LWJGL 2 و 3 الأصلية لتفادي أي تعارض في ملفات النظام.
- **حل الشاشة السوداء في كروت الشاشة الهجينة:** فحص وتطهير تلقائي لملف `options.txt` عند الإقلاع لإلغاء أي تعارضات في نمط الشاشة الكاملة (DWM Deadlocks) على أجهزة اللابتوب المزودة بكروت Intel/NVIDIA Optimus.
- **محرك إدارة دورة حياة النافذة:** إخفاء المشغل أثناء اللعب مع إعادته تلقائياً وفورياً إلى الواجهة الأمامية بمجرد إغلاق اللعبة، مع القضاء التام على نوافذ GDI+ الشبحية في شريط المهام.
- **استوديو السكنات والأوشحة ثلاثي الأبعاد:** عارض WebGL تفاعلي مدمج يعتمد على Three.js / SkinView3D، يتيح معاينة السكنات بنمطي Classic و Slim، مع إمكانية تحريك السكن وحفظه محلياً وسحابياً.

### 2. المثبت الذكي SIR Installer (`SIR Installer.exe`)
- **فحص استباقي لسلامة الجهاز:** التحقق من صلاحيات الكتابة، وإصدارات الجافا المثبتة قبل بدء العملية.
- **التدفق السحابي الذاتي والاستشفاء:** تحميل الحزم والملفات الناقصة عبر تشفير TLS 1.3 مع فحص دقيق للبصمات الرقمية (CRC32 و SHA-256).
- **ترقية آمنة بنسبة 100%:** لا يقوم المثبت بمسح عوالمك الفردية (Saves)، أو لقطات الشاشة (Screenshots)، أو إعداداتك المفضلة عند الترقية للإصدارات الأحدث.

### 3. مدير الخوادم SIR Server Manager (`SIR Server Manager.exe`)
- **استضافة خوادم بدون بورتات (Zero-Port Tunneling):** تكامل حصري ومباشر مع أنفاق **Playit.gg** المدمجة، مما يتيح لك إنشاء خادم محلي ودعوة أصدقائك عبر رابط عام مباشر دون الحاجة للدخول إلى إعدادات الراوتر أو إجراء Port Forwarding.
- **رادار الأداء الحي:** عدادات لحظية لمعدل المعالجة TPS (Ticks Per Second)، ونسبة استهلاك المعالج والذاكرة.
- **لوحة خيارات دورة حياة النافذة المتقدمة:** تخصيص سلوك إغلاق وتصغير النافذة والتشغيل التلقائي مع بدء تشغيل ويندوز وحفظها تلقائياً.

## 6. منصة الويب وخدمات السحابة (sir-modpack.web.app)

تتصل المنظومة ببوابة ويب فائقة السرعة مبنية بأحدث معايير الويب العالمية:
- **معمارية حديثة بالكامل:** تطبيق **Next.js 16 App Router** مع **React 19** و **Tailwind CSS v4**، يشمل 38 مساراً ساكناً مسبق المعالجة (Prerendered Static Routes) بما في ذلك صفحة سياسة الاسترجاع والانسحاب القانوني الرقمي (`/refund`).
- **مساعد SIR Diagnostic & Configuration Assistant:** أداة مساعدة تشخيصية متطورة تساعدك على فحص التوافق وتهيئة الإعدادات وتحليل الانهيارات البرمجية.
